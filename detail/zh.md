# 侧边助理

一个挂在会话右栏里的中文助手：它不干活，只负责把话说清楚，并替你转达给主会话。

## 它提供什么

- **「侧边助理」会话模式**：新建会话时可选。它只有一个中文人设，没有 shell、没有文件工具，不碰你的代码。
- **三个工具**（只在「侧边助理」会话里出现）：

  | 工具 | 作用 |
  |---|---|
  | `side_sessions` | 列出当前工作区里的其他会话，标出哪些在跑、哪个是主会话 |
  | `side_peek` | 读某个会话最近的对话主线：说了什么、答了什么、调用了哪些工具、每轮怎么结束的 |
  | `side_deliver` | 把整理好的需求投递给主会话并唤醒它，对方那边显示为「来自会话 …」 |

- **右侧栏面板**：在任意会话头部点「侧边助理」，右栏会打开它的聊天面板；面板里就是那个独立会话，你可以直接跟它说话。

## 用法

1. 打开任意会话，点头部「侧边助理」，右栏出现面板。
2. 用中文随口说你的需求。它会先问清楚目标、做到什么程度、哪些不能动。
3. 你说「发给主会话」，它把整理后的需求投递过去。
4. 你说「跟进一下」，它会读主会话最近的进展，回来给结论、说验证到哪、问你要不要拍板。

## 设计取舍

- **会话是真正独立的 Session**：右栏面板只是它的一个视图，关掉面板不会杀掉会话。
- **投递走 `agent.followup`**：只有「活着的」会话能被唤醒；没在跑的会话会明确报错，而不是假装发过去了。
- **工具按 agent 作用域注册**：插件本身是 profile 级的一行，`agent/created` 命中「侧边助理」预设时才给那一个会话注册工具，普通会话看不到。
- **不依赖宿主包的裸导入**：插件不 `import '@deepseek-ai/*'`，工具定义自己组装成标准 JSON Schema，避免在 preset 子行里解析失败。

## 改完代码怎么生效

- 改 `lib/index.js`（host 侧）：在插件页把「侧边助理」关一次再开，或让主会话执行一次重新加载。
- 改 `lib/client.js`（界面侧）：在页面里按 `Ctrl+R` 刷新。

## 已知边界

- 右栏面板复用官方 `sidebar.chat.conversation` 座位；如果 DSH 改了那个座位形状，面板需要跟着调整。
- 标签标题固定显示「侧边助理」。
